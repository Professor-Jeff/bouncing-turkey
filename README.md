# The Bouncing Turkey

**Live:** https://professor-jeff.github.io/bouncing-turkey/

A single-file, in-browser puzzle for COMP 220. A turkey hides in one of the
boxes and jumps a fixed number of boxes left or right every time you open an
empty one, and every jump must land cleanly inside the row. Design a sequence of guesses that always
finds it, then let classmates challenge the claim by designing a turkey path
that dodges every guess. The "Smart turkey" button searches for a dodge
itself and settles the argument.

## Deploying

Edit `index.html` and push to `main`. GitHub Pages redeploys within about a minute.
