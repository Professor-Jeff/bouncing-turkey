# The Bouncing Turkey

**Live:** https://professor-jeff.github.io/bouncing-turkey/

A single-file, in-browser puzzle for COMP 220. A turkey hides in one of the
boxes and jumps a fixed number of boxes left or right every time you open an
empty one, bouncing off the ends. Design a sequence of guesses that always
finds it, then play it back with X-ray on to see why it works.

## Deploying

Edit `index.html` and push to `main`. GitHub Pages redeploys within about a minute.
